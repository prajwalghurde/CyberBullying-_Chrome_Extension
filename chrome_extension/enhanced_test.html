What Should Happen:

Troubleshooting:

  • If text doesn't appear, try selecting it again and immediately clicking the extension
  • Check Chrome console (Ctrl+Shift+J) for any error messages
  • Refresh the webpage if the content script isn't loading properly
  • Verify the extension has proper permissions in chrome://extensions
